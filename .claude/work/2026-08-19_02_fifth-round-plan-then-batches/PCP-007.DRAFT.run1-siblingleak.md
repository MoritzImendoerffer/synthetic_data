# PCP-007 run 1 — set aside: sibling prose reached the draft through `DISCREPANCIES.md`

**2026-08-21, TASK-029 §3.** The mechanical audit lists were both **empty** — `suspect: []` and
`other qmd: []` over 33 commands — and the draft still has to be set aside, because the acceptance
criterion's first clause ("Reads of only the allowed inputs and code") is the one that failed.

## The offending command

```
cat authoring/DISCREPANCIES.md
```

`authoring/DISCREPANCIES.md` is not a `.qmd`, so the `other qmd` filter does not see it, and it
contains no measurement keyword, so the `suspect` filter does not see it either. What it contains
is **verbatim prose from four sibling documents**: the D-001 section quotes PCP-006, PCP-008 and
PCP-009 sentence for sentence, paraphrases PCP-003's, and the D-002 section quotes PCR-003.

## The leak reached the text

`DISCREPANCIES.md`, quoting PCP-008:

> "The first holds the other parameters at their set-points and evaluates the fitted
> response surface model across the parameter's characterization range."

and quoting PCP-009:

> "… on a grid of 201 points, using the fitted response-surface model."

The set-aside draft, §8.2:

> "The first analysis holds the other parameters at their set-points and evaluates the fitted
> response surface model for the parameter of interest across its characterization range, on a
> grid of `{python} par_grid_sp` points."

PCP-008's clause and PCP-009's grid clause, fused. This is the sibling-copying loop the campaign
exists to break, arriving through a file the audit was not written to catch.

## Why the author went there

The brief's own §5c sends it. §5c reads "None" for PCP-007 and then adds: "The registry is
`authoring/DISCREPANCIES.md`; an *unregistered* inconsistency is a bug." The author followed a
pointer that an allowed input handed it. The defect is in the apparatus, not in the agent's
discretion, which is what makes it a finding rather than only a discarded draft.

## Disposition

Draft set aside as evidence (`.qmd` and `.pdf` beside this note). A fresh agent was re-launched
with the **same prompt verbatim** — the regime is frozen, so the prompt was not amended to name
`DISCREPANCIES.md`, and the defect goes to the results page (TASK-040) instead. If the second
agent reads the same file, the finding is structural rather than incidental and this session stops
and reports rather than launching a third.
